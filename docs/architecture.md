# Структура и сценарии

`/projects` → `/projects/[slug]` → `/quote`

## Пользовательские сценарии

1. Посетитель выбирает услугу или проект и за один переход открывает расчёт.
2. Конфигуратор передаёт выбранный автомобиль, пакет, фактуру, цвет и дополнительные работы в форму через URL.
3. Форма последовательно собирает автомобиль, услугу, пожелания, фото и контакт. Фото проверяются по реальному содержимому, уменьшаются и перекодируются WebP; EXIF не переносится.
4. Сервер валидирует заявку и заново рассчитывает цену. После сохранения пытается отправить подтверждение и CRM-событие. Ошибка интеграции не уничтожает заявку.
5. Запись резервирует слот консультации; транзакция блокирует конкурирующее бронирование того же времени. Календарь использует Europe/Moscow, рабочие дни Пн–Сб и горизонт 60 дней.
6. Вошедший клиент видит только созданные его сеансом заявки. Администратор задаёт CRM-статус и отдельный этап выполнения, документы, гарантию и рекомендации.

## Модули

- `src/app` — страницы и серверные route handlers; динамический каталог читается при запросе, без устаревшего статического портфолио.
- `components/shell`, `ui` — навигация, типографика, CTA, подвал, cookies.
- `hero`, `media` — video/poster, native fullscreen dialogs, галереи и comparison slider.
- `portfolio`, `services` — представление и фильтрация данных каталога.
- `car`, `configurator`, `ppf` — SVG-зоны и цвет кузова; стекло и колёса не перекрашиваются.
- `quote-form`, `booking-form` — состояние форм, загрузка, валидация, loading/error/success.
- `account`, `dashboard`, `admin` — клиентские интерфейсы поверх проверяемых сервером прав.
- `lib/catalog`, `calculator` — данные и чистые бизнес-правила.
- `lib/db`, `auth`, `validation`, `http`, `integrations` — хранение, сессии, схемы, ограничение тела запросов и адаптеры внешних сервисов.

## Данные

`catalog`: услуги, проекты, материалы, отзывы, настройки бренда. Изменения валидируются целиком; повторные ID и slug отклоняются.

`users` / `sessions`: роли и хешированные токены сеансов; пароли scrypt с индивидуальной солью.

`leads`: конфигурация, контакты, серверный ориентир, документы; CRM-статус отдельно от этапа производства.

`bookings`: дата, время, связь с заявкой; unique partial index исключает CANCELLED.

`uploads`: приватная capability, владелец и признак привязки. Угадывание имени файла не даёт доступа к фотографии.

`limits`: счётчики ограничений. `events`: состояние попыток email/CRM.

Начальные кейсы иллюстративные; реальная выручка считается только по COMPLETED и согласованной сумме. Начальные метрики не выдумываются.

## Расчёт

Базовая цена берётся из редактируемого каталога. Купе ×1, седан ×1.1, SUV ×1.2. Для винила Metallic / Color shift / Carbon — ×1.15. Дополнительные работы суммируются без дубликатов. Округление до 1000 ₽. Срок увеличивается на день при наличии дополнений.

PPF: Front / Track / Full с ценами, пропорциональными базовой цене полной защиты в каталоге. Это ориентир, а не финальная оферта.

## Дизайн и поведение

Фон #080808, поверхности #111111 / #191919, текст #F5F5F5, красный #FF1E1E. Отступы, цвета, ширины и длительности — CSS variables. Сетка крупных секций, тонкие разделители и минимум скруглений. Manrope для русского текста, Barlow Condensed для крупных латинских заголовков; шрифты загружаются локально.

Breakpoints 1100 / 800 / 520 px. На смартфонах — одна колонка, полноэкранное меню и фиксированный CTA. Видео фона не воспроизводится на мобильных устройствах и при reduced motion; poster остаётся видимым.

Анимации CSS 180–600 мс, небольшое увеличение фото, reveal hero, скролл-прогресс. Тяжёлые библиотеки движения и 3D не подключаются. Native range и dialogs поддерживают клавиатуру, анимации не нужны для завершения сценариев.

## Развёртывание

Это приложение для одного Node-инстанса с постоянным диском. PostgreSQL, object storage, mail retry-worker и восстановление пароля через верифицированный email — отдельные расширения перед соответствующим масштабированием. Не включены оплаты: ТЗ предусматривает их только при необходимости.

HTTPS нужен для production-сеансов. Перед публикацией задаются домен, контакты, разрешённое портфолио, юридические сведения и необходимые интеграции. Развёртывание на stateless/serverless-хосте без постоянного диска для этой версии не подходит.
